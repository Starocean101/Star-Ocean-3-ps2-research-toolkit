# Copyright and Data Policy

This repository is intended for interoperability, preservation, and technical
research using legally obtained game media.

Do not commit:

- ISO images;
- executable files from the game;
- original IRX/ELF modules;
- extracted game archives;
- textures, models, audio, video, scripts, or other proprietary assets;
- decrypted bulk game content.

Permitted project material includes original source code, documentation,
pseudocode, addresses, file-format descriptions, hashes, synthetic fixtures,
and user-generated test data.

The project is not affiliated with tri-Ace, Square Enix, Sony, or the original
publishers and rights holders.
