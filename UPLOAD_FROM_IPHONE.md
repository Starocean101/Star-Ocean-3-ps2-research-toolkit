# Upload This Package to GitHub from iPhone

This ZIP contains the files that belong at the root of the repository.

## Reliable method: Working Copy

1. Install **Working Copy** from the App Store.
2. In Working Copy, clone the GitHub repository.
3. In the iPhone Files app, extract this ZIP.
4. Select the extracted contents, not the outer folder.
5. Share or copy them into the cloned repository in Working Copy.
6. Review the changed files.
7. Commit with:

```text
Add browser extractor and initial technical research
```

8. Push the commit to GitHub.

This preserves all folders in one operation.

## GitHub website method

The GitHub mobile website can upload multiple files, but folder uploads are
awkward and may flatten or omit structure depending on the picker.

For a few individual files:

1. Open the repository.
2. Tap the three-dot menu beside the green **Code** button.
3. Choose **Add file** → **Upload files**.
4. Select files.
5. Commit changes.

For this complete package, Working Copy is the safer route.

## Important

Do not upload the ZIP itself as the final repository contents. GitHub will store
it as one ZIP and will not unpack it. Extract it first and commit the contents.
