# Publish the update from iPhone

## Recommended: Working Copy

1. Clone or open `Starocean101/Star-Ocean-3-ps2-research-toolkit` in Working
   Copy.
2. Create branch `release/v5.12.8-pass6.2`.
3. Extract the returned repository ZIP in Files.
4. Import the extracted **contents** into the repository root. Do not import the
   outer ZIP folder as a nested directory.
5. Allow matching Version 1 files to be replaced.
6. Review the staged file list. It must contain no ISO, executable, decoded
   actor resource, movie/audio sample, or private evidence directory.
7. Commit with:

   `Publish SO3 Resource Explorer V5.12.8 Pass 6.2`

8. Push the branch and merge it on GitHub after reviewing the comparison.

For the complete checklist and optional release tag, see
`WORKING_COPY_UPDATE_INSTRUCTIONS.md`.

Do not commit the repository ZIP itself. Commit its extracted contents.
