# Source

`build_release.py` assembles the deterministic single-file browser from the
V5.1 baseline plus the versioned JavaScript modules in this directory.

The portable Python movie and SAC decoders are included for independent command
line validation. Engine-analysis runners accept user-supplied legally obtained
inputs; no executable or actor fixture is bundled.
