# Copyright and data policy

This repository supports interoperability, preservation, and technical
research using legally obtained game media.

Do not commit:

- ISO, ROM, or disc images;
- game executables, IRX/ELF/MWo3 modules, or memory images;
- decoded hidden allocations or original archives;
- extracted textures, models, animations, maps, audio, movies, or scripts;
- screenshots or other redistributed game artwork;
- private engine responses or full proprietary-memory traces.

Permitted project material includes original tools, documentation, pseudocode,
addresses, hashes, file-format descriptions, synthetic fixtures, derived
metadata, and bounded numerical decoder constants required for interoperability.

`02_SOURCE/so3_sac_vu_tables.bin` is a reconstructed 16 KiB numerical decoder
coefficient image. It is not an executable, disc allocation, audio stream, or
extracted artwork asset. See `PUBLICATION_BOUNDARY.md`.

The `v5_fis.js` module is a GPL-3.0-or-later port; its license and notice are in
`02_SOURCE/`. No license has yet been selected for the repository's remaining
original code and documentation.

This project is not affiliated with tri-Ace, Square Enix, Sony, or the original
publishers and rights holders.
